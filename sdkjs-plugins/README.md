## Description

The editors provide a style sheet for different interface elements. To adjust your plugin interface to the editor style, connect the [plugin.css](v1/plugins.css) to your plugin's [index.html](https://euro-office.github.io/documentation/development/plugins/) file with the following link:

`<link rel="stylesheet" href="https://onlyoffice.github.io/sdkjs-plugins/v1/plugins.css">`

Plugin styles (controls) include:

* Different types of buttons
* Input controls (text area, text field, checkbox)
* Label controls (header label, link label)
* Combo box
* Loader

For more details and examples, please refer to the [plugin developer documentation](https://euro-office.github.io/documentation/development/plugins/).

# Structure

* [v1](v1): This directory contains the stylesheets and CSS files used for plugin customization and styling.
* [content](content): This directory contains the code and resources of all plugins. How to add your own plugin read [here](../store/).
